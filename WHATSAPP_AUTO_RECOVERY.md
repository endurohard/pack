# Автоматическое восстановление WhatsApp

Система автоматического обнаружения и исправления проблем с инициализацией WhatsApp.

## 🎯 Что было сделано

### 1. Автоматическая очистка при запуске (встроено в код)

В `src/whatsappManager.js` добавлена функция `cleanupOldBrowserProcesses()`, которая:
- ✅ Автоматически обнаруживает зависшие процессы Chrome
- ✅ Проверяет наличие блокирующих файлов (SingletonLock, SingletonCookie, SingletonSocket)
- ✅ Завершает зависшие процессы Chrome
- ✅ Удаляет блокирующие файлы
- ✅ Запускается автоматически при каждой инициализации WhatsApp

**Теперь при каждом запуске сервера проблема с браузером решается автоматически!**

### 2. Скрипт мониторинга и восстановления

Создан `whatsapp-monitor.sh` со следующими возможностями:

```bash
# Проверка состояния WhatsApp
./whatsapp-monitor.sh check

# Очистка зависших процессов
./whatsapp-monitor.sh cleanup

# Полный перезапуск сервера
./whatsapp-monitor.sh restart

# Постоянный мониторинг (проверка каждые 5 минут)
./whatsapp-monitor.sh start
```

### 3. Автоматическая установка мониторинга

Создан `setup-whatsapp-monitor.sh` для простой настройки:

```bash
./setup-whatsapp-monitor.sh
```

Предлагает 3 варианта:
1. **Cron** (рекомендуется) - автоматическая проверка каждые 5 минут
2. **Systemd** - постоянный сервис в фоне
3. **Только в коде** - автоматическая очистка только при запуске

## 📋 Как использовать

### Вариант 1: Автоматическая очистка при запуске (уже работает)

**Ничего делать не нужно!** Система уже настроена.

При каждом запуске `node src/server.js` автоматически:
- Проверяются зависшие процессы
- Очищаются блокирующие файлы
- WhatsApp запускается без ошибок

### Вариант 2: Регулярный мониторинг через Cron (рекомендуется)

```bash
# Запустите скрипт установки
./setup-whatsapp-monitor.sh

# Выберите вариант 1 (Cron)
```

После установки:
- Проверка WhatsApp каждые 5 минут
- Автоматический перезапуск при проблемах
- Логи в `whatsapp-monitor.log`

**Просмотр логов:**
```bash
tail -f whatsapp-monitor.log
```

### Вариант 3: Постоянный мониторинг через Systemd

```bash
# Запустите скрипт установки
./setup-whatsapp-monitor.sh

# Выберите вариант 2 (Systemd)
```

**Управление сервисом:**
```bash
sudo systemctl status whatsapp-monitor    # Статус
sudo systemctl restart whatsapp-monitor   # Перезапуск
sudo journalctl -u whatsapp-monitor -f    # Логи
```

## ❓ FAQ

**Q: Нужно ли что-то настраивать вручную?**
A: Нет! Автоочистка уже работает при каждом запуске. Мониторинг - опционально.

**Q: Как часто запускается проверка?**
A: При установке через Cron - каждые 5 минут. Можно настроить.

**Q: Что делать, если WhatsApp все равно не запускается?**
A: Запустите `./whatsapp-monitor.sh restart` или проверьте логи.

**Q: Можно ли отключить мониторинг?**
A: Да. Для Cron: `crontab -e` и удалите строку. Для Systemd: `sudo systemctl disable whatsapp-monitor`

**Q: Влияет ли это на производительность?**
A: Нет. Автоочистка работает только при старте, мониторинг - раз в 5 минут.
