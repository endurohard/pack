# Исправления системы счетов

**Дата**: 8 марта 2026
**Проблема**: Счет 149 был отправлен с неправильным файлом (Pancho вместо Лайм)

## Выявленные проблемы

### 1. Дублирование номеров счетов
- Счет №149 был создан дважды для разных клиентов:
  - 6 февраля 2026 - для клиента "Pancho"
  - 8 марта 2026 - для клиента "Лайм"
- Система позволяла создавать счета с одинаковыми номерами

### 2. Выбор неправильного файла при отправке
- При отправке счета с дублирующим номером использовался метод `.find()`
- Метод возвращал первый попавшийся файл, а не самый актуальный
- В результате отправлялся старый файл Pancho вместо нового файла Лайм

## Реализованные исправления

### 1. Умный выбор файла с приоритетом по имени клиента (src/server.js:1469-1511)

**Изменения**:
- Заменен `.find()` на `.filter()` для поиска всех файлов с номером счета
- **Приоритет 1**: Поиск файла по имени клиента из базы данных
- **Приоритет 2**: Если файл с именем не найден - выбирается самый свежий по дате модификации
- Добавлено предупреждение в лог при обнаружении дубликатов
- Оптимизирован код - убрано дублирование запроса к БД

**Алгоритм**:
1. Получаем данные счета из БД по номеру
2. Ищем все файлы с этим номером счета
3. Если найдено несколько файлов:
   - Пытаемся найти файл, содержащий имя клиента из БД
   - Если найден - используем его
   - Если не найден - сортируем по дате и выбираем самый новый

**Код**:
```javascript
// Получаем информацию о счете из БД
const invoice = db.getInvoiceByNumber(invoiceId);

if (matchingFiles.length > 1) {
  // Пытаемся найти по имени клиента
  if (invoice && invoice.client) {
    const clientNameClean = sanitizeFilename(invoice.client);
    const fileWithClientName = matchingFiles.find(f => f.includes(clientNameClean));

    if (fileWithClientName) {
      pdfFile = fileWithClientName;
      console.log(`✅ Выбран файл по имени клиента "${invoice.client}": ${pdfFile}`);
    } else {
      // Fallback: выбираем самый свежий
      // ... сортировка по mtime ...
    }
  }
}
```

### 2. Проверка дублирования при создании счета (src/server.js:205-217)

**Изменения**:
- Добавлена проверка существования счета с таким номером перед созданием
- При попытке создать дубликат возвращается ошибка 400
- В ответе указывается информация о существующем счете

**Код**:
```javascript
const existingInvoice = db.getInvoiceByNumber(invoiceNumber);
if (existingInvoice) {
  console.warn(`⚠️  Попытка создания дублирующего счета №${invoiceNumber}`);
  return res.status(400).json({
    error: `Счет с номером ${invoiceNumber} уже существует`,
    details: {
      existingClient: existingInvoice.client,
      existingDate: existingInvoice.invoiceDate,
      existingAmount: existingInvoice.amount
    }
  });
}
```

### 3. Проверка дублирования при обновлении счета (src/server.js:557-570)

**Изменения**:
- Проверка на дубликат при изменении номера существующего счета
- Предотвращение переименования счета на уже занятый номер

### 4. Проверка при дублировании счета (src/server.js:1013-1021)

**Изменения**:
- Дополнительная проверка после генерации номера счетчиком
- Обнаружение критических ошибок в работе счетчика
