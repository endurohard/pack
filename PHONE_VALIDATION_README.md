# Система контроля номеров телефонов

## Проблема

Была обнаружена проблема с отправкой счетов по WhatsApp: счета отправлялись не тем клиентам из-за несоответствия номеров телефонов в счетах и в базе клиентов.

### Выявленные причины:

1. **Несоответствие имен клиентов**: В базе счетов клиенты записывались с кавычками (например, `"Salat"`), а в базе клиентов без кавычек, что приводило к невозможности найти соответствующего клиента.

2. **Неправильные номера телефонов**: В некоторых счетах были указаны неверные номера (например, счет №114 имел номер `+79297777776` вместо `+79287777776`).

3. **Отсутствие проверки**: Система не проверяла соответствие номеров перед отправкой.

## Решение

Создана комплексная система валидации и контроля номеров телефонов:

### 1. PhoneValidator (`src/phoneValidator.js`)

Модуль для валидации и исправления номеров телефонов:

- **Нормализация имен клиентов**: Автоматически убирает лишние кавычки при поиске клиентов
- **Нормализация номеров**: Приводит номера к единому формату (+7XXXXXXXXXX)
- **Валидация**: Проверяет соответствие номеров в счетах и базе клиентов
- **Автоматическое исправление**: Может автоматически исправить неправильные номера

### 2. Интеграция в AutoSendScheduler

Добавлена автоматическая проверка и исправление номеров перед отправкой (строки 318-338 в `src/autoSendScheduler.js`):

- Перед отправкой каждого счета система проверяет номер телефона
- Если номер неправильный, но клиент найден - номер автоматически исправляется
- Если клиент не найден - отправка отменяется с выводом ошибки

### 3. API Endpoints

Добавлены новые API endpoints для управления валидацией:

#### GET `/api/phone-validation/report`
Получить полный отчет по всем счетам:
```json
{
  "success": true,
  "report": {
    "total": 71,
    "valid": 69,
    "invalid": 2,
    "missingClient": 2,
    "missingPhone": 0,
    "issues": [...]
  }
}
```

#### GET `/api/phone-validation/auto-send-report`
Получить отчет только по счетам с автоотправкой:
```json
{
  "success": true,
  "report": {
    "autoSendCount": 16,
    "total": 16,
    "valid": 16,
    "invalid": 0,
    "issues": []
  }
}
```

#### GET `/api/phone-validation/:invoiceId`
Проверить конкретный счет:
```json
{
  "success": true,
  "invoice": {
    "number": "114",
    "client": "Арслан \"Парная для души\"",
    "currentPhone": "+79297777776"
  },
  "validation": {
    "valid": false,
    "clientFound": true,
    "expectedPhone": "+79287777776",
    "message": "Номер не соответствует"
  },
  "fix": {
    "success": true,
    "changed": true,
    "correctPhone": "+79287777776",
    "oldPhone": "+79297777776"
  }
}
```

#### POST `/api/phone-validation/fix-all`
Автоматически исправить все номера:
```json
{
  "success": true,
  "results": {
    "total": 71,
    "fixed": 1,
    "skipped": 68,
    "errors": 2,
    "details": [...]
  }
}
```

#### POST `/api/phone-validation/fix/:invoiceId`
Исправить номер конкретного счета:
```json
{
  "success": true,
  "message": "Номер исправлен: +79297777776 → +79287777776",
  "invoice": {
    "number": "114",
    "client": "Арслан \"Парная для души\"",
    "oldPhone": "+79297777776",
    "newPhone": "+79287777776"
  }
}
```

## Использование

### Проверка всех счетов

```bash
node check-phones.js
```

Покажет детальный отчет о состоянии номеров телефонов во всех счетах.

### Тестирование системы валидации

```bash
node test-validation.js
```

Запустит полное тестирование системы валидации.

### Просмотр проблемных счетов

```bash
node show-issues.js
```

Покажет список всех счетов с неправильными или отсутствующими номерами.

### Исправление конкретного счета

```bash
node fix-invoice-114.js
```

Пример скрипта для исправления номера в конкретном счете.

## Техническая информация

### Нормализация номеров

Все номера приводятся к формату `+7XXXXXXXXXX`:
- `8XXXXXXXXXX` → `+7XXXXXXXXXX`
- `9XXXXXXXXX` → `+79XXXXXXXXX`
- `+7XXXXXXXXXX` → остается без изменений

### Поиск клиентов

Система ищет клиентов с учетом:
- Точного совпадения имени
- Нормализованного имени (без лишних кавычек)
- Например, `"Salat"` найдет клиента `Salat` и наоборот

### Логирование

Все операции валидации и исправления логируются с префиксами:
- `[AutoSend]` - операции планировщика
- `[PhoneValidator]` - операции валидации
- Уровни: ✅ успех, ⚠️  предупреждение, ❌ ошибка, 🔧 исправление

## Поддержка

При возникновении проблем с отправкой счетов:

1. Проверьте отчет валидации: `node check-phones.js`
2. Посмотрите логи в консоли сервера
3. Используйте API endpoint `/api/phone-validation/report` для диагностики
4. При необходимости используйте `/api/phone-validation/fix-all` для автоматического исправления
