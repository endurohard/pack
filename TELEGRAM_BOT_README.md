# Telegram бот для управления счетами

Telegram бот позволяет управлять счетами прямо из мессенджера.

## Возможности бота

- ✅ **Создание счетов** - создавайте счета с выбором клиента и товаров через интерактивные кнопки
- 📋 **Просмотр счетов** - смотрите список всех счетов с их статусами
- 💰 **Управление оплатой** - отмечайте счета как оплаченные
- 📤 **Отправка в WhatsApp** - отправляйте PDF счета клиентам через WhatsApp прямо из бота
- 📊 **Статистика** - просматривайте общую статистику по счетам

## Конфигурация

Бот уже настроен и готов к работе! Конфигурация находится в файле `telegram-config.json`:

```json
{
  "botToken": "8214850189:AAFUHf7om1UDzzOEpXwRYciZZ1RnnJU8WXs",
  "allowedUserId": 398885257,
  "enabled": true
}
```

- **botToken** - токен вашего бота
- **allowedUserId** - ваш Telegram ID (только вы можете использовать бота)
- **enabled** - включен ли бот (true/false)

## Запуск

Бот запускается автоматически вместе с основным сервером:

```bash
npm start
```

В логах вы увидите:
```
[TelegramBot] Конфигурация загружена
[TelegramBot] Бот успешно запущен
```

## Использование

1. Найдите вашего бота в Telegram (имя бота зависит от того, как вы его создавали)
2. Отправьте команду `/start`
3. Выберите нужное действие из меню

### Создание счета

1. Нажмите "➕ Создать счет"
2. Выберите клиента из списка
3. Выберите товары/услуги (для каждого товара укажите количество)
4. Нажмите "✅ Завершить создание счета"
5. После создания можно сразу отправить счет в WhatsApp или отметить как оплаченный

### Просмотр счетов

1. Нажмите "📋 Список счетов" для просмотра всех счетов
2. Нажмите "💰 Неоплаченные счета" для просмотра только неоплаченных
3. Выберите счет из списка для просмотра деталей

### Статус счетов

- ✅ - Полностью оплачен
- ⚠️ - Частично оплачен
- ❌ - Не оплачен

## Отключение бота

Если нужно временно отключить бота, измените в `telegram-config.json`:

```json
{
  "enabled": false
}
```

И перезапустите сервер.

## Безопасность

- Бот работает только с вашим Telegram ID (398885257)
- Все другие пользователи получат сообщение "❌ У вас нет доступа к этому боту"
- Токен бота хранится в конфигурационном файле - не публикуйте его в открытых репозиториях

## Особенности

- Бот использует long polling для получения обновлений
- Не требует дополнительных библиотек (работает на axios)
- Автоматически запускается при старте сервера
- Работает независимо от веб-интерфейса
