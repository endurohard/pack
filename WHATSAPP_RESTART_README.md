# Автоматическая перезагрузка WhatsApp после отправки счетов

## Описание функциональности

Добавлена возможность автоматической перезагрузки WhatsApp-сессии после отправки каждого счета в системе автоматической рассылки.

## Зачем это нужно?

Перезагрузка WhatsApp после каждой отправки помогает:

1. **Избежать зависания браузера** - длительная работа Chromium может привести к утечкам памяти
2. **Обновить соединение** - свежая сессия WhatsApp Web работает стабильнее
3. **Предотвратить ошибки** - сбрасывает накопившиеся проблемы в браузере
4. **Улучшить надежность** - каждая отправка происходит в "чистой" среде

## Как это работает

### Процесс автоматической отправки с перезагрузкой:

1. Система отправляет счет клиенту через WhatsApp
2. Обновляет информацию о счете в базе данных
3. **Перезагружает WhatsApp** (если включено в настройках):
   - Закрывает текущий браузер Chromium
   - Ждет 2 секунды
   - Запускает новый экземпляр браузера
   - Подключается к WhatsApp Web
   - Ждет 10 секунд для стабилизации
4. Ждет 5 минут перед отправкой следующего счета
5. Повторяет процесс для следующего счета

### Таймлайн отправки (пример для 3 счетов):

```
00:00 - Отправка счета №1
00:01 - Перезагрузка WhatsApp (2 сек закрытие + 10 сек инициализация)
00:06 - Ожидание (5 минут)
05:06 - Отправка счета №2
05:07 - Перезагрузка WhatsApp
05:17 - Ожидание (5 минут)
10:17 - Отправка счета №3
10:18 - Перезагрузка WhatsApp
10:28 - Завершение
```

## Настройки

### Включение/выключение автоперезагрузки

Настройка хранится в файле `data/whatsapp-settings.json`:

```json
{
  "greeting": "...",
  "reminder": "...",
  "sendTimeHour": 10,
  "sendTimeMinute": 0,
  "testMode": false,
  "testPhone": "79096194444",
  "restartWhatsAppAfterSend": true
}
```

**Параметр `restartWhatsAppAfterSend`:**
- `true` (по умолчанию) - перезагружать WhatsApp после каждой отправки
- `false` - не перезагружать WhatsApp

### Изменение настройки через API

**Включить перезагрузку:**
```bash
curl -X POST http://localhost:3000/api/whatsapp/settings \
  -H "Content-Type: application/json" \
  -d '{"restartWhatsAppAfterSend": true}'
```

**Выключить перезагрузку:**
```bash
curl -X POST http://localhost:3000/api/whatsapp/settings \
  -H "Content-Type: application/json" \
  -d '{"restartWhatsAppAfterSend": false}'
```

**Проверить текущие настройки:**
```bash
curl http://localhost:3000/api/whatsapp/settings
```

### Изменение через веб-интерфейс

В будущем можно добавить переключатель в интерфейс настроек (страница `/settings`).

## Логирование

Все действия перезагрузки логируются с префиксом `[AutoSend]`:

### Когда перезагрузка включена:

```
[AutoSend] ✅ Счет №143 успешно отправлен
[AutoSend] Следующая отправка: 01.03.2026, 10:13:18
[AutoSend] 🔄 Перезагрузка WhatsApp после отправки...
[AutoSend] ✅ WhatsApp успешно перезагружен
```

### Когда перезагрузка выключена:

```
[AutoSend] ✅ Счет №143 успешно отправлен
[AutoSend] Следующая отправка: 01.03.2026, 10:13:18
[AutoSend] ⏭️  Перезагрузка WhatsApp отключена в настройках
```

### При ошибке перезагрузки:

```
[AutoSend] ✅ Счет №143 успешно отправлен
[AutoSend] 🔄 Перезагрузка WhatsApp после отправки...
[AutoSend] ⚠️  Ошибка перезагрузки WhatsApp: Failed to launch browser
```

**Важно:** Даже если перезагрузка не удалась, система продолжит работу и попытается отправить следующий счет.

## Технические детали

### Код перезагрузки

Расположение: `src/autoSendScheduler.js`, строки 223-237

```javascript
// Перезагружаем WhatsApp после успешной отправки (если включено в настройках)
if (settings.restartWhatsAppAfterSend !== false) { // По умолчанию true
  console.log(`[AutoSend] 🔄 Перезагрузка WhatsApp после отправки...`);
  try {
    await this.whatsappManager.restart();
    console.log(`[AutoSend] ✅ WhatsApp успешно перезагружен`);
    // Ждем 10 секунд после перезагрузки для стабилизации
    await this.sleep(10000);
  } catch (restartError) {
    console.error(`[AutoSend] ⚠️  Ошибка перезагрузки WhatsApp:`, restartError.message);
    // Продолжаем работу даже если перезагрузка не удалась
  }
} else {
  console.log(`[AutoSend] ⏭️  Перезагрузка WhatsApp отключена в настройках`);
}
```

### Метод restart()

Расположение: `src/whatsappManager.js`, строки 984-989

```javascript
async restart() {
  console.log('🔄 Перезапуск WhatsApp...');
  await this.close();
  await new Promise(resolve => setTimeout(resolve, 2000));
  await this.initialize();
}
```

## Рекомендации

### Когда использовать автоперезагрузку:

✅ **Включить** (`true`):
- При отправке большого количества счетов (5+)
- Если замечены проблемы со стабильностью WhatsApp
- Для продакшн среды с критичными рассылками
- При работе на сервере с ограниченной памятью

❌ **Выключить** (`false`):
- При тестировании (для ускорения процесса)
- Если отправляется 1-2 счета
- Если WhatsApp работает стабильно
- Для экономии времени (сокращает цикл отправки на ~12 секунд на счет)

### Оптимизация времени

**С перезагрузкой** (по умолчанию):
- Время на отправку 1 счета: ~1 секунда
- Время на перезагрузку: ~12 секунд
- Ожидание между счетами: 5 минут
- **Итого на 1 счет**: ~5 минут 13 секунд

**Без перезагрузки**:
- Время на отправку 1 счета: ~1 секунда
- Ожидание между счетами: 5 минут
- **Итого на 1 счет**: ~5 минут 1 секунда

**Экономия**: 12 секунд на каждый счет
**Но**: возможна нестабильная работа при большом количестве отправок

## Мониторинг

### Проверка работы системы:

```bash
# Посмотреть логи сервера
pm2 logs

# Или если запущено напрямую
tail -f server.log

# Проверить статус автоотправки
curl http://localhost:3000/api/auto-send/status
```

### Признаки проблем:

1. **Зависание**: Счет отправлен, но перезагрузка не происходит
   - Решение: Проверить логи, перезапустить сервер

2. **Ошибки перезагрузки**: В логах появляется "Ошибка перезагрузки WhatsApp"
   - Решение: Проверить доступность X11 (DISPLAY=:99), перезапустить Xvfb

3. **WhatsApp не подключается**: После перезагрузки QR-код не сканируется
   - Решение: Проверить сессию WhatsApp, возможно нужно заново отсканировать QR
